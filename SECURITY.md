# Security policy

## Supported versions

Only the latest release of Skill Canvas gets security fixes. Please update before reporting.

## Reporting a vulnerability

Please don't open a public issue, discussion or pull request for a security problem.

Report it privately through GitHub instead: [open a security advisory](https://github.com/alaturqua/skill-canvas/security/advisories/new). Only you and the maintainers can see it.

Include what you can:

- What the problem is and what an attacker could do with it
- Steps to reproduce, or a small `.skillcanvas` file that shows it
- Skill Canvas version, VS Code version and operating system
- Any idea you have for a fix

## What happens next

We aim to respond within 7 days. That's a goal, not a promise. We'll confirm the problem, work on a fix, and credit you in the advisory unless you'd rather stay anonymous.
